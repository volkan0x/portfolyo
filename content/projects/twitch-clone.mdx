The live channels and categories are currently presented as static demo content. The project does not implement real live streaming, chat, subscriptions, payments, or a working search backend.

## services included

- GitHub authentication through NextAuth, allowing users to sign in, view their profile details, and sign out.
- Account page that displays the signed-in user’s name, email address, and profile image.
- Live channel showcase with stream thumbnails, channel names, game categories, and creator profiles.
- Content category browsing for games and genres such as FPS and shooter games.
- Embedded video content through a YouTube player in the hero section.
- Responsive navigation with desktop and mobile menus.
- Search interface for discovering streams or content.
- Twitch CDN media usage for stream previews, profile images, and game artwork.
