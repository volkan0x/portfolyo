the application utilizes web scraping to extract product prices from a given URL(works only for trendyol.com now) and sends e-mail notifications using the gmail SMTP server.

## services included:

- Web scraping: Retrieves product pages and extracts prices from Trendyol.
- Price comparison: Checks whether a product’s price is at or below the user’s target price.
- Email notifications: Sends an alert through Gmail SMTP when the target price is reached.
- Web form: Lets users submit a product URL, target price, and email address.
- Local data storage: Uses TinyDB to store tracking records.
- Vercel configuration: Includes deployment settings for hosting the Python application on Vercel.
