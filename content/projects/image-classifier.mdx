It runs locally and does not include a web API, database, authentication system, or external user-facing service.

## services included:

- Local image selection: Users can choose JPG or PNG images from their computer.
- Image preview: The selected image is resized and displayed in the application window.
- AI image classification: Uses TensorFlow/Keras with the pretrained VGG16 model trained on ImageNet.
- Prediction results: Shows the top predicted image categories with confidence percentages.
- Desktop graphical interface: Built with Tkinter.
