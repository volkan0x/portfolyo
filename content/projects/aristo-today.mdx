## services included:
- OpenWeather API	Retrieves city coordinates, current conditions, and five day forecasts in three hour intervals.
- IPAPI	Detects the visitor’s city from their IP address to display local weather.
- Windy	Provides an embedded interactive wind map.
- Vercel Analytics	Collects website usage and visitor analytics.
- Server-side cache	Stores geocoding data for 24 hours and forecasts for 10 minutes to reduce OpenWeather API requests.™
- SEO features	Generates canonical URLs, Open Graph data, Twitter cards, structured data, and a dynamic sitemap.xml.

User-facing features include city search, weather forecasts for Turkish provinces, IP-based local forecasts, temperature, humidity, precipitation probability, and a wind map.
